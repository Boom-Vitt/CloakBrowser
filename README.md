## 🧐 นี่คืออะไร?

ลองนึกภาพว่าคุณอยากเข้าเว็บไซต์หรือใช้บัญชีหลายอันพร้อมกัน แต่ไม่อยากให้เว็บไซต์รู้ว่าทุกอันมาจากคอมพิวเตอร์เครื่องเดียวกัน

**ตัวจัดการโปรไฟล์เบราว์เซอร์** ช่วยให้คุณสร้าง "เบราว์เซอร์" ได้หลายตัว โดยแต่ละตัวจะมี **ตัวตนของอุปกรณ์ที่ต่างกันโดยสมบูรณ์** — เหมือนคุณมีคอมพิวเตอร์หลายเครื่องวางเรียงกัน ทั้งที่จริง ๆ ใช้เครื่องเดียว

แต่ละโปรไฟล์จะแยกขาดจากกัน มีคุกกี้ การล็อกอิน และข้อมูลของตัวเอง และจะถูกบันทึกไว้แม้ปิดโปรแกรมไปแล้ว ทุกอย่างทำงานผ่าน **หน้าเว็บที่ใช้ง่าย** เปิดในเบราว์เซอร์ปกติของคุณได้เลย

> เป็นทางเลือกที่ **ฟรี** แทนโปรแกรมเสียเงินอย่าง Multilogin, GoLogin และ AdsPower

## 🤔 ทำไมต้องใช้? (VPN ไม่พอเหรอ?)

หลายคนเข้าใจว่าใช้ VPN หรือเปิดโหมดไม่ระบุตัวตน (Incognito) แล้วจะปลอดภัย แต่จริง ๆ แล้ว **ยังไม่พอ**:

- **VPN** เปลี่ยนแค่ที่อยู่ IP เท่านั้น
- **โหมดไม่ระบุตัวตน** แค่ลบคุกกี้
- **โปรไฟล์ Chrome หลายอัน** ก็ยังใช้ "ลายนิ้วมือ" ของเครื่องเดียวกันอยู่ดี

เว็บไซต์สมัยใหม่ใช้สัญญาณกว่า 50 อย่างเพื่อจับว่าบัญชีไหนมาจากเครื่องเดียวกัน ทำให้ทุกบัญชีของคุณถูกเชื่อมโยงกันได้

**ตัวจัดการโปรไฟล์เบราว์เซอร์** สร้างตัวตนของอุปกรณ์ใหม่ทั้งหมดให้แต่ละโปรไฟล์ ทำให้เว็บไซต์มองว่าแต่ละโปรไฟล์เป็น "คนละเครื่อง" จริง ๆ

| วิธีที่คนนิยมใช้ | เปลี่ยนอะไร | บัญชียังถูกเชื่อมโยงกันไหม? |
|---|---|---|
| VPN | แค่ที่อยู่ IP | ❌ ยังถูกเชื่อมโยง (ลายนิ้วมือเดิม) |
| โหมดไม่ระบุตัวตน | แค่ลบคุกกี้ | ❌ ยังถูกเชื่อมโยง (ลายนิ้วมือเดิม) |
| โปรไฟล์ Chrome | แยกบุ๊กมาร์ก/คุกกี้ | ❌ ยังถูกเชื่อมโยง (ลายนิ้วมือเครื่องเดิม) |
| **ตัวจัดการโปรไฟล์ CloakBrowser** | **ทุกอย่าง — ตัวตนของอุปกรณ์ใหม่ทั้งโปรไฟล์** | ✅ **ไม่ถูกเชื่อมโยง** |

## ✨ ทำอะไรได้บ้าง

- **สร้างโปรไฟล์ได้ไม่จำกัด** แต่ละอันมีตัวตนของเครื่องที่ไม่ซ้ำกัน
- **เปิด/ปิดได้ด้วยคลิกเดียว** แต่ละโปรไฟล์ทำงานแยกกันอย่างอิสระ
- **จำการล็อกอินไว้ให้** คุกกี้และการเข้าสู่ระบบยังอยู่แม้ปิดไปแล้วเปิดใหม่
- **ดูและคลิกใช้งานได้ในหน้าเว็บ** ไม่ต้องเปิดโปรแกรมแยก
- **ตั้งค่าพร็อกซีแยกแต่ละโปรไฟล์ได้** เลือกโซนเวลา ภาษา และอื่น ๆ ได้
- **เนียนเหมือนคนจริง** เบื้องหลังใช้เทคโนโลยี CloakBrowser ที่ผ่านการตรวจจับบอทของเว็บใหญ่ ๆ ได้

> ⚠️ **โปรดใช้อย่างถูกต้องตามกฎหมายและกติกาของแต่ละเว็บไซต์** เครื่องมือนี้มีไว้เพื่อความเป็นส่วนตัวและการจัดการบัญชีของคุณเองอย่างสุจริต ไม่สนับสนุนการใช้งานที่ผิดกฎหมายหรือละเมิดข้อกำหนดของผู้ให้บริการ

## 🚀 วิธีติดตั้ง — แค่ "บอก Claude" ให้ทำให้

คุณ **ไม่ต้องพิมพ์คำสั่งหรือเขียนโค้ดใด ๆ เลย** เพียงให้ **Claude** เป็นคนติดตั้งและเปิดให้คุณ

> 📌 **สิ่งที่ต้องมีก่อน:** ต้องติดตั้ง **Claude Code** ไว้ในเครื่องก่อน (ทำครั้งเดียว) ดูวิธีติดตั้งได้ที่ [คู่มือเริ่มต้นใช้งาน Claude Code](https://docs.claude.com/en/docs/claude-code/quickstart) — ถ้าติดขัดตรงนี้ ลองให้เพื่อนที่พอใช้คอมเป็นช่วยติดตั้งให้ครั้งแรก จากนั้นที่เหลือคุณบอก Claude เองได้หมด

**ขั้นตอน:**

1. เปิด **Claude Code** (โปรแกรม Claude ที่สั่งงานในเครื่องคอมพิวเตอร์ของคุณได้)
2. พิมพ์ข้อความนี้บอก Claude ตรง ๆ (ก๊อบไปวางได้เลย):

> ช่วยติดตั้งและเปิด **CloakBrowser Profile Manager** ให้หน่อยครับ/ค่ะ
> (จาก https://github.com/CloakHQ/CloakBrowser-Manager )
> ถ้าในเครื่องยังไม่มีโปรแกรมที่จำเป็น (เช่น Docker) ช่วยติดตั้งให้ด้วย
> เสร็จแล้วบอกวิธีเปิดหน้าเว็บให้ผม/ฉันด้วยนะ

3. รอให้ Claude ทำให้เสร็จ — Claude จะจัดการทุกอย่างให้เอง
4. เมื่อเสร็จ Claude จะบอกลิงก์สำหรับเปิดหน้าเว็บ (โดยทั่วไปคือ **http://localhost:8080** ) ให้เปิดลิงก์นั้นในเบราว์เซอร์ของคุณ

แค่นี้ก็พร้อมใช้งานแล้ว 🎉

## 🖱️ วิธีใช้งาน

1. เปิดลิงก์ที่ Claude บอก (เช่น **http://localhost:8080** ) ในเบราว์เซอร์
2. กดปุ่ม **สร้างโปรไฟล์ใหม่ (Create Profile)**
3. กดปุ่ม **เปิด (Launch)** ที่โปรไฟล์นั้น
4. เบราว์เซอร์ของโปรไฟล์จะปรากฏขึ้นในหน้าเว็บ — คุณคลิก พิมพ์ และใช้งานได้เหมือนเบราว์เซอร์ทั่วไป

อยากได้หลายตัวตน? ก็แค่สร้างโปรไฟล์เพิ่มอีกหลาย ๆ อัน แต่ละอันจะเป็นเหมือนเครื่องใหม่เสมอ

## 🆘 ถ้าติดปัญหา — ก็บอก Claude อีกที

ถ้ามีอะไรไม่เป็นไปตามที่ควร ไม่ต้องกังวล แค่บอก Claude ตามจริง เช่น:

> เปิดหน้าเว็บ http://localhost:8080 ไม่ขึ้นเลย ช่วยตรวจสอบและแก้ให้หน่อย

Claude จะช่วยตรวจสอบและแก้ไขให้ โดยที่คุณไม่ต้องรู้เรื่องเทคนิคเลย
